PROJECT OVERVIEW
════════════════════════════════════════════════════════════════════════════════

A professional, production-ready visual pipeline builder for data analysis.
Users build complex workflows by dragging and dropping nodes, then get
executable Python code automatically generated.

Similar to: Snap (scratch blocks), Unreal Blueprints, but for data science!


KEY FEATURES IMPLEMENTED
════════════════════════════════════════════════════════════════════════════════

✅ VISUAL PIPELINE BUILDER
   • PyQt6-based GUI with drag-and-drop interface
   • Canvas for visual workflow construction  
   • Node palette with 11+ node types
   • Color-coded nodes by category
   • Property inspector for viewing/editing details

✅ COMPLETE NODE LIBRARY
   • Data Loading: CSV (extensible to other formats)
   • Preprocessing: Normalize, Handle Missing, Feature Selection, Train/Test Split
   • Analysis: Correlation, Clustering, Regression
   • Visualization: Generic visualization nodes
   • AI Models: Claude API, GPT API, Open Weights placeholder
   • Custom Code: Execute functions from your repositories

✅ PIPELINE GRAPH ENGINE
   • Directed Acyclic Graph (DAG) implementation
   • Node and edge management
   • Cycle detection and validation
   • Topological sorting for correct execution order
   • Full serialization to/from JSON

✅ AUTOMATIC CODE GENERATION
   • Generates executable Python code from visual pipeline
   • Smart import management based on used nodes
   • Per-node code generation with parameter substitution
   • Ready-to-run Python scripts

✅ SAVE/LOAD PIPELINES
   • Persist pipelines as .pipeline JSON files
   • Preserve visual layout on load
   • Share pipelines with team members
   • Full serialization/deserialization

✅ REPOSITORY MANAGEMENT
   • Framework for uploading custom code repositories
   • Metadata persistence and management
   • Integration with pipeline nodes
   • Ready for Python AST parsing

✅ AI MODEL INTEGRATION
   • Claude API client
   • GPT API client  
   • Open weights placeholder for future expansion
   • Configuration management system

✅ PROFESSIONAL PACKAGE
   • Modern pyproject.toml configuration
   • Installable via: pip install -e .
   • Console script entry point: analysis-gui
   • Development dependencies included
   • Ready for PyPI distribution

QUICK START
════════════════════════════════════════════════════════════════════════════════

1. INSTALL
   cd /Users/neelimavalluru/Desktop/AnalysisGUI
   pip install -e ".[dev]"

2. LAUNCH
   analysis-gui

3. BUILD A PIPELINE
   • Double-click nodes in left panel to add them
   • View properties on the right
   • Click "Generated Code" to see Python

4. SAVE & LOAD
   • File → Save Pipeline (saves as .pipeline JSON)
   • File → Open Pipeline (loads your saved pipeline)

5. RUN GENERATED CODE
   • Copy code from right panel
   • Save to .py file
   • Execute with Python
